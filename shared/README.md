# Shared utilities (placeholder)

This folder is reserved for utilities, configurations, or preprocessing
steps that are **shared across the proteomics and fMRI branches** of
TCG-Net — for example, common subject-ID handling, train/val/test split
schemes that must be aligned across modalities, or shared logging
helpers if/when those are extracted from `proteomics/utils/`.

It is currently empty pending integration planning. Nothing should land
here until both encoder branches are mature enough to identify what
genuinely needs to be shared (vs. coincidentally similar).
