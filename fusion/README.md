# Cooperative Shapley Fusion (placeholder)

This folder is reserved for the **Cooperative Shapley Fusion Module** of
TCG-Net. The module integrates the proteomics-side embedding `z_p`
(produced by `proteomics/`) and the fMRI-side embedding `z_f` (produced
by `fmri/`) through a cooperative game-theoretic fusion mechanism, and
produces the final cognitive-target prediction together with
individualised mechanistic interpretations.

- **Branch:** `shapley-fusion`
- **Status:** development is started **after** both the proteomics and
  fMRI encoders have been completed and merged into `main`. The fusion
  module is joint work between the two encoder authors.

This folder is currently empty pending that work.
