# fMRI encoder (placeholder)

This folder is reserved for the fMRI connectome encoder branch of TCG-Net.

It will contain the **GCN-GAT connectome encoder** described in the TCG-Net
design document — a graph neural network that consumes resting-state
functional connectomes and emits the modality-specific embedding `z_f`
that the Cooperative Shapley Fusion Module pairs with the proteomics
embedding `z_p`.

- **Branch:** `fmri-encoder`
- **Owner:** developed by a separate team member; the proteomics and fMRI
  branches progress in parallel and are integrated only at the fusion stage.

This folder is currently empty pending that work.
